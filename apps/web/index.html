Transfer from a screen to a camera.

No Wi-Fi, no Bluetooth, no server. The two devices recognize each other through a code you compare, then the file travels through the image, encrypted and verified byte for byte.

Send from this screen

Optical mode

TM8 first; while sending, a button switches to TM4 if the phone struggles.

Grids on screen

Several frames at once: up to sixteen times faster, but the phone must be closer to the screen. Beyond 3 × 3, you need a receiver that films in 4K.

Subframe duration

250 ms can be read live by any phone. 33 ms and below: film in slow-mo.

The code from the test bench calibration sets the duration and the mosaic in one go.

Receive with the camera

On a phone, the rear camera reads better; white balance and exposure are locked as soon as the grid is in frame.
