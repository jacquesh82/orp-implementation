The principle · TM4 / TM8

The file changes form.
Light makes the connection.

With TM4 and TM8, OptiRelay turns data into optical matrices. A reference image, then a payload image: the camera reads their difference to reconstruct the file.

Explore the protocol
  1. 01

    Prepare · TM4

    The first exchange uses TM4, the more robust mode. Both devices prepare the optical session.

  2. 02

    Display · TM4 / TM8

    TM4 carries 2 bits per module; TM8 carries 3. Each frame alternates a reference subframe and a payload subframe.

  3. 03

    Capture

    The camera reads the difference between the two subframes. The receiver collects the data and reconstructs the file.

  4. 04

    Verify

    The reconstructed stream is checked against its SHA-256 digest before the file is made available.
